# Travel Guide Reference

## 1. 定位

`travel-guide` = 轻量玩吃推荐 + 多日实证攻略（小红书优先）+ HTML 交付。  
同仓时**优先本 Skill**，旧 `travel-skill` / `xhs-travel-skill` 仅归档参考。

---

## 2. 分流判定

| 信号 | 档位 |
|------|------|
| 半天 / 一天 / 晚上、去哪玩/吃、避人流（未要攻略页） | 轻量 |
| **≥2 天**、周末未指明天数（默认 2 天）、攻略/HTML、自驾/假期、预算表 | 攻略 |
| 仅天气 / 仅 A→B 路线 / 仅开放时间票价 | 工具短答 |

### Phase 1 一次问卷默认

| 项 | 未答 |
|----|------|
| destination | 硬挡，只追问目的地 |
| origin | 可定稿，标「待补出发地」 |
| return_destination | 未答 → **等于 origin**；与 origin 不同则末日路书/电车按返程终点算 |
| content_focus | 均衡 |
| crowd_preference | 适中 |
| travel_type | 朋友 |
| ev_range_km（电车） | **硬挡充电日程定稿** |

### 自驾 / 电车

```text
是否自驾？
  ├─ 否 → 公共交通；origin/return 空则大交通「待补」
  └─ 是 → 油 / 混 / 电
              └─ 电 → 必问 ev_range_km
                    基准 ≤ 续航×0.7
                    冬/高寒/雨雪 ≤ ×0.55～0.6
                    盛夏长高速可 ×0.65
                    末段里程按「末站 → return_destination」计算（默认 return=origin）
```

- 桩位：规划参考 + 出行前小程序核验，不伪称实时空位  
- 轻量市内半日/一日：默认不问自驾，除非用户提跨城自驾  

### 内容侧重 vs 题材偏好

| 字段 | 管什么 |
|------|--------|
| `content_focus` | 玩 vs 吃的**日程比重**（未答=均衡） |
| `preference` | 自然/人文/亲子/摄影等**题材滤镜** |
| `intent`（轻量） | 只吃/只玩 ≈ 偏美食/偏景点 |

适宜人群：同行 + 检索归纳「适合谁 / 不太适合谁」，**不伪装官方评级**。

## 3. 人流等级（轻量+攻略日程）

| 等级 | 含义 | 用户理解 |
|------|------|----------|
| `S` | 超级热门 | 大概率人多，需排队或错峰 |
| `A` | 热门 | 周末节假日较挤 |
| `B` | 中等 | 多数时间可接受 |
| `C` | 小众 | 相对安静 |
| `D` | 冷门 | 很安静，适合明确避人流 |

### 偏好映射

| 用户偏好 | 优先 | 可接受 | 尽量回避 |
|----------|------|--------|----------|
| 热闹 | S、A | B | D |
| 适中 | A、B | C | S、D |
| 人少 | C、D | B | S |

- 热门城市可保留少量不完全匹配点，**必须**口头提醒人流风险  
- 第一次来：不要整条线都是 D  
- 对用户用自然语言，不必输出字母等级

## 4. 轻量档 profile 示例

```json
{
  "destination": "杭州",
  "intent": "都要",
  "crowd_preference": "人少",
  "duration": "半天",
  "travel_type": "情侣",
  "budget": "300-500",
  "first_time": true,
  "known_info": ["想拍夜景", "不想排太久队"],
  "mode": "light"
}
```

缺省：`intent=都要`，`crowd_preference=适中`，`duration=一天`，`travel_type=朋友`，`first_time=未知`。

筛选：目的地 → 人流映射 → 时长/预算 → 题材/线索 → 场景排序。

## 5. 攻略档研究与 MCP

小红书维：攻略天数、避坑、费用、住宿、美食、拍照；按 content_focus / 同行加减维；电车加充电维。  
公开网：票价开放时间、交通、住宿、预约、天气、大交通（依赖 origin，缺则待补）；门票官方/OTA 实链（不造 ID）。

融合：价格实测 > 标价 > 估算；踩坑评论 > 正文 > 公开网；路线高赞 + 地理可行。

| MCP | 说明 |
|-----|------|
| 默认 | `x-mcp`（插件在线 + 小红书已登录） |
| 备选 | [xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp) |

工具：`check_login_status`、`search_feeds`、`get_feed_detail`。  
**`search_feeds`：默认不传 `filters`。**

小红书失败：仍出 HTML + 摘要并声明原因。

## 6. 预算结构（写入 HTML）

```text
people, days
origin_note: 有则写出发地，无则「待补出发地」
items[]: name, unitPrice, subtotal, note
totals: economy / comfort / luxury
savingTips[]
disclaimer
```

## 7. 产出检查（攻略档）

- [ ] 攻略档已先出粗规划并获确认（或用户明确跳过）后再写 HTML/PDF  
- [ ] 存在 `*_travel_guide.html`，含侧重/适宜人群占位（电车含充电块）；`<title>` 等 `{{…}}` 已全部替换  
- [ ] 对话含：定位、每日主题、适宜谁、三档预算、避坑、路径  
- [ ] 若无小红书：摘要有失败声明  
- [ ] 自驾已确认；电车已有续航；季节折损已按日期处理  
- [ ] origin 空：大交通/跨城已标待补  
- [ ] content_focus 有值（含默认均衡）；crowd 有值（含默认适中）  
- [ ] 选点已评论核验：网红非一刀切；差评多则降级；出片位核验通过可进主线或 photo-fold，并写排队成本  
- [ ] 有老人/小孩时日程已降强度或拆轻松备选  
- [ ] 每日有 `.day-weather`（气温/现象/降水 + 穿衣；超远日期为气候向+「出行前再核」）  
- [ ] 明显降水日有 `.rain-alt` 雨备替换线（非仅「带伞」）  
- [ ] 每日有路书条；各停靠点有导航关键词+地址（或明确「以门店为准」）  
- [ ] 重要玩吃节点旁有「来源」行（无链接则综合公开渠道，不造假 URL）  
- [ ] 适用景点节点有 `.ticket-line`（免票也写；参考价+预约状态；OTA/官方实链或明确「搜店名核验」；禁止伪造商品 ID）  
- [ ] 适用景点：`.day-rail-row` 左右分栏（主线左；tips/play/photo 与亮点/提醒同右轨）；无侧栏用 `.spot-side--empty`  
- [ ] 重要提醒：屏上默认最多 3 条，多出进 tip-more 折叠；打印展开  
- [ ] 精简后仍保留可点来源（链挂关键词或笔记行）；未为省字删 explore URL  
- [ ] 同日路线/时长/到点未在路书+提醒+侧栏三处复读  
- [ ] 适用景点有 `.spot-play`（时长 / 重点区 / 避堵）；注意点有 `.spot-tips`+来源；评论无法直链时用「打开笔记看评论」  
- [ ] 出片穿搭用 `.photo-fold` 默认折叠；打印可展开  
- [ ] 待办/预算在右侧抽屉；float-dock 有「待办」「预算」；打印仍含全文；勾选仍写本机  
- [ ] 正文无明显 AI 套话（值得一提/不容错过/完美结合等）  
- [ ] 节假日/行前待办含「再核开放时间与局部封闭」  
- [ ] 电车：充电时段与用餐高峰错峰或已写明先后顺序  
- [ ] 预约购票汇总表含购票链接列，与节点信息不矛盾  
- [ ] 文末有折叠「攻略参考地址」（去重；不含高德/购票深链/图源）；打印可展开  
- [ ] 配图：本地 `media/` 或 Wikimedia/Openverse 等可标注源；未热链/截图小红书原图；页脚有 `.img-disclaimer`  
- [ ] 总览为日卡片（含顶图更好）+ `›` 分隔，无贯穿连线；配图达标或已省略且无裂图  
- [ ] 预约与行前准备紧挨每日行程之后（`.prep-cluster`）；待办抽屉 `data-todo-key` 可用  
- [ ] 携带/注意/行前准备为可勾选待办，含进度文案；刷新后勾选仍在（同浏览器）  
- [ ] HTML/PDF 已写入 `guides/<slug>/`（含 `meta.json`）；摘要已提示 push 更新站点  
- [ ] 页面默认 `data-theme` 已设，含右下角悬浮条（配色 + 待办 + 预算 + 导出 PDF）；摘要已询问是否换肤  
- [ ] 已生成同目录 `*_travel_guide.pdf`（或摘要已声明打印失败原因）；摘要已提示国内同行优先发 PDF  
- [ ] 若用户要 URL：优先腾讯云/阿里云/Gitee；GitHub/CF 仅备选并提醒国内访问风险；无托管勿编造 URL  
- [ ] 页面无外链字体 CDN、可打印（C 打印有浅色回退）；地图链为可选深链
